站长工作台.

这是站长入口，不是可直接改字的编辑器。网页内容存放在 GitHub 仓库里；你需要从下面进入真正的 Pages CMS 表单后台，或使用 GitHub 网页编辑。保存并提交后，网站才会自动更新。

① 进入真正的表单编辑器

Pages CMS 是独立的编辑网站，不在本页直接输入文字。点击下方按钮会打开新页面；选择「Sign in with GitHub」，用 Child-of-the-Unbound-Lord 登录，进入名为 Song-of-Righteousness-in-Mathematics-and-Physics 的仓库，并确认分支是 main。

打开 Pages CMS 表单编辑器 ↗ 首次安装 Pages CMS App ↗

只有第一次需要在 GitHub 中授权 Pages CMS。授权时可选择 Only select repositories，并只勾选这一个仓库。之后在表单里改简介、文章、研究方向或项目，点击保存即可提交到 GitHub，自动发布工作流会接着运行。

即使别人打开本站的「站长工作台」，也不能因此取得编辑权限；实际读写权限由 GitHub 登录及 App 授权控制。检查已安装的 GitHub Apps ↗

③ 看不到编辑按钮？按这里排查

  1. 只能看到此管理页：正常。本页是入口，点击上面的「打开 Pages CMS 表单编辑器」。
  2. Pages CMS 里看不到仓库：到 GitHub Apps 设置 检查 Pages CMS 是否安装、授权的仓库是否正确；没安装先点击上面的安装按钮。
  3. 看到了仓库但找不到栏目：确认选择的是 main 分支，且仓库根目录存在 .pages.yml 配置。如果栏目长时间不刷新，先重新进入仓库，避免使用旧的缓存配置。
  4. 编辑后网站没有更新：确认保存生成了 GitHub 提交，再检查 自动发布记录；只有部署成功才会影响公开页面。
