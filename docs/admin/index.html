评论设置 · giscus 配置助手

评论会对应首页或每篇文章的独立讨论。访客点击“载入评论”后才会连接第三方 giscus 服务，登录 GitHub 后才能发言。

仓库状态 正在检测…
  1. 仓库 Settings → General → Features → 勾选 Discussions。
  2. 安装 giscus GitHub App，只选择此仓库并同意所请求权限；这一步必须由仓库管理员完成。
  3. giscus 配置器中输入本仓库，选择一个 Discussions 分类，复制生成的嵌入代码。
  4. 将代码粘贴到下面，点击“提取分类”，再复制配置至 comments.yml 编辑页，或通过 Pages CMS“GitHub 评论设置”表单填写。

仓库 ID 已核实，无需重新查找。这里生成的是公开配置，不包含密码或私密密钥。只有完成授权并使用正确的 Category ID，评论功能才可以真正启用。

注意：GitHub Discussions 中的评论是公开的。站长可在 Discussions 管理页审核与回复。
