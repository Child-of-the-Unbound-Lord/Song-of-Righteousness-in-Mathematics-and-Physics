其他可编辑内容

「首页和关于我」：名称、身份、介绍、联系方式、栏目文案。

「研究方向」「项目列表」「论文与成果」：增加、删除、排序和编辑结构化条目。

「四套角色主题」：修改主题名字、配色关联文案与插画路径；媒体库允许上传图片。

「GitHub 评论设置」：填好 giscus 参数后直接切换启用。

评论设置（首次需要授权）

打开 仓库 Settings，在 General → Features 开启 Discussions。到 giscus GitHub App 安装页面，仅授予此仓库权限。最后打开 giscus 配置器 复制 Category ID，在内容后台的「GitHub 评论设置」中粘贴，打开「启用评论」。

注意：评论数据存储在公开的 GitHub Discussions 中，管理员可通过 GitHub 管理；这些评论不是私密留言。

在哪里看发布结果？

编辑完成点击保存后，打开 网站自动发布工作流 查看状态。完成后前往 公开首页 检查。原始 Markdown 和 YAML 文件永远保存在 GitHub 仓库中，可以回退历史版本。
